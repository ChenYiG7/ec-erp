## 二期(约 6 周)

国内链路完整:电子面单(CLODOP 打单)、拆合单、采购(单/入库/供应商)、售后、完整仓内作业(盘点/调拨)、内销订单、Webhook 通知(飞书/钉钉/企微)、XXL-Job 接入、第二个国内平台 adapter。

## 三期(约 8 周)

跨境纵深:Amazon 结算报告解析、FBA Shipment、多仓库存(海外仓/FBA)、补货规划、利润核算 + 汇率、广告报表抓取、AI 自然语言查询(@Tool)、报表 BI。

## 四期(规划)

多商户、平台横向铺开(每平台 1-2 周复制接入)、AI 客服/动态定价(启用 AgentScope,依赖已预埋)、OpenAPI 对外。

## 风险清单

| 风险 | 应对 |
|---|---|
| AppKey 拿不到 | 备选:第三方 API 服务(需评估稳定性与合规),或先跨境(Amazon 门槛低) |
| 平台 API 配额限制 | Gateway 按 shop 限流 + 拉长轮询间隔 + 推送通道优先 |
| 单人开发周期长 | 严守一期范围,二三期功能一律不做 |
| 汇率/税务合规复杂 | 三期利润核算先做简化口径(下单日汇率),细化放四期 |
