# 09 前端开发规范守则(erp-web)

> 适用范围:`erp-web/`(Geeker Admin v2 底座,Apache-2.0,二次开发声明见 erp-web/README)。
> 基线:**Vue 官方风格指南 A/B 级 + Element Plus 官方规约**;本文只写项目裁剪/偏差/铁律,通用规约不复述。
> 后端对应规约见 docs/07;TODO(编号) 约定、devlog 纪律、Token 纪律见根 CLAUDE.md,前后端同规。

## 1. 技术栈定版与升级纪律【2026-09-05 定版】

| 依赖 | 版本 | 说明 |
|---|---|---|
| Vue / Vite / TS | 3.5 / 8.0.16(Rolldown) / 6.0 | 底座 Geeker-Admin v2(main 分支),底座 commit 见 erp-web/README |
| Element Plus | 2.14 线 | 锁 2.x,3.x(如有)需拍板 |
| Pinia / vue-router | 3.0 / 5.1 | persistedstate 做 token/字典持久化;router 用 hash 模式(后端无前端路由 fallback) |
| UnoCSS | 66(preset-wind4) | 原子类做布局间距;业务色/复杂样式仍走 scoped scss |

| pnpm | 11.8(packageManager 锁定) | node ≥22.12;禁 npm/yarn 安装(only-allow 已内置) |

- **落地即锁 pnpm-lock.yaml**,禁随手 `pnpm up` 追大版本;Vite 9 / EP major / TS 7 等新大版本线一律拍板后才动,升级只动 package.json 一处并全量回归门禁。
- 新增依赖先过三问:是否底座已有等价物(如日期格式化用 dayjs 而非 moment)?是否会被打进生产 chunk?许可证是否与 Apache-2.0 兼容?登记进本表。

## 2. 目录分层与 api 收口【红线】

```
erp-web/src/
├── api/apis/<module>/<domain>.ts   # 业务请求函数唯一居所(按后端模块分目录)
├── api/interface/                  # TS 类型中枢(对齐后端 response/request,禁手抄漂移)
├── views/<module>/<domain>/        # 页面(ProTable 范式)+ components/ 页面私有组件
├── stores/modules/                 # pinia:global/user/auth/tabs/dict/notification
├── utils/request/                  # axios 封装(双错误形态唯一收口,业务禁改)
├── components/                     # 跨页面公共组件(ProTable/Dict/TreeFilter…)
└── tools/                          # 代码生成器(开发工具,非运行时依赖)
```

- **红线:组件/store 禁 `import axios`、禁拼 URL 直连**;一切请求走 `src/api/apis/` 函数,一切路径以 `/api` 开头写后端全路径(baseURL 留空走 vite proxy,禁 rewrite)。
- 类型一律 import 自 `@/api/interface/**`;后端加字段 → `pnpm api:sync` 刷新快照 → 重新生成/手补类型,**禁前端自造重复类型**。
- KeepAlive 生效前提:页面 `defineOptions({ name })` 必须 = 路由 name = component 路径 `/`→`-`(如 `shop/index` → `shop-index`);生成器已按此产出,手写页面同规。

## 3. 请求与响应规约【双错误形态唯一收口】

后端契约事实(与 docs/07 §2/§3 对齐):`Result{code,msg,data}` 成功 code=200;时间 `yyyy-MM-dd HH:mm:ss` GMT+8 直显;金额 DECIMAL(12,4) 按 string。

1. **Result 解包止步 data**:响应拦截器(http 200 且 body.code=200)已返回 `body.data`,业务代码只见业务数据,**禁在页面再解一层 `.data`**。
2. **双错误形态统一在 `src/utils/request/base.ts` 收口**,业务禁重复处理:
   - 形态一:MVC 异常 = HTTP 200 + `code≠200` → 拦截器 ElMessage.error(msg) + reject;
   - 形态二:Security = 真实 HTTP 状态码 + Result JSON → 401 清 token 跳登录(带 redirect,并发防抖只处理一次)、403 warning 提示、其余走 statusMessages。
3. **分页字段差异只在生成的 api `page` 函数内收口**:入参后端 `pageNo/pageSize` vs 模板 `pageNum`,出参后端 `records` vs 模板 `list` ——页面侧永远只见 `{list,total}`;**禁在页面里做 records/list 换算**(差异点超过一处 = 还债信号)。
4. 排障:`error.traceId` 取自 `X-Trace-Id` 响应头,提 bug 时附上;**禁 console 打完整响应体**(§10)。
5. **JWT 24h 无 refresh token:401 即重登,禁造续期/轮询刷新逻辑**。

## 4. ProTable 配置化范式

- 新 CRUD 页**一律生成器起步**(§11);ProTable 必传 `pageId`(= 路由 path,列设置缓存键)/`columns`/`requestApi`。
- 列配置即文档:搜索项 = `search: { el: 'input'|'select'|… }`;枚举/字典 = `enum`(静态数组或 `() => Promise<{label,value}[]>`,**两种同时供单元格格式化与搜索下拉**);标签列 `tag: true` + enum 项 `tagType`。
- **filterEnum 用 `===` 严格相等**:数字形态的枚举/字典值必须收敛 Number(spec 解析层已做;手写页面注意)。
- 操作列 = columns `type:'operation'` + 页面 `#operation` 插槽(**v2 必须提供插槽**,否则运行时取 `slots.operation!` 报错);工具栏新增按钮走 `#toolbarLeft` 插槽 + `v-auth`——**`toolbarLeft` prop 的 `auth` 属性无效,禁用**(已知坑)。
- 树形表格/详情驱动页(无分页)属例外:分页关掉、`requestApi` 换数据源、写清注释;禁硬套分页范式。
- 删除等破坏性操作先 `ElMessageBox.confirm`;完成后 `proTableRef.getTableList()` 刷新,**禁手动改 tableData**。

## 5. 表单与校验

- 新增/编辑共用 `<Entity>Form.vue` 弹窗(生成器产物):`open(mode, row)` 打开,edit 浅拷贝行数据(**禁直接引用污染列表行**),成功 emit `saved` 由页面刷新。
- rules 集中声明,必填 message 与控件匹配(输入=blur / 选择=change);提交 `:loading="submitting"` + `validate()` 前置,**禁双击重复提交**。
- 复杂校验(跨字段/远程查重)生成器不产,人工补时写在 Form 内,不动公共组件。

## 6. 金额红线【全端铁律,前后端同规】

- 后端 DECIMAL(12,4) 序列化值在前端**一律 string 类型直存直显**(生成器对 spec 标 money 的字段已产 string + 注释)。
- **禁 `parseFloat`/`Number` 参与金额运算**(精度丢失);展示格式化允许千分位字符串处理。
- 确需前端计算的(如行小计汇总预览),**拍板后才可引 decimal 库**(如 decimal.js),并把计算收敛到单一 util,禁散落组件。

## 7. 权限【路由级 + 按钮级】

- 路由:登录/刷新均以 `GET /api/auth/me` 的 menus 树重建动态路由(`dynamicRouter.ts`);menuType 1目录/2菜单/3按钮;`visible=0`→隐藏;`component` 无对应视图 → console.error 明确报错,**禁静默白屏**。
- 按钮:`v-auth="'module:domain:action'"`,值 = 后端 permKey(全局唯一);判定在 auth store 扁平 `perms` 集合。
- **约定:`perms` 为空 = 引导期(sys_menu 尚无 menuType=3 种子),放行**;非空后严格判断。权限只做展示层裁剪,越权拦截在后端 @PreAuthorize,前端判一次仅为准入提示。
- 401 即重登(§3.5);**禁前端造"权限不足"业务分支**(真 403 由拦截器统一提示)。

## 8. Pinia store 划分

| store | 职责 | persist |
|---|---|---|
| user | token + 用户信息 | localStorage |
| auth | perms + 菜单树(由 /me 装配,不持久化,刷新重建) | 否 |
| dict | 按 dictType 惰性加载缓存 30 天 | localStorage |
| notification | 未读数 60s 轮询(visibilitychange 暂停/恢复) | 否 |
| tabs / global / loading | 模板原生职责 | 按模板 |

- **禁把页面私有状态上抬到 store**;跨页面共享才进 store,进 store 的字段必须在本表登记职责。
- setup store **不支持 `$reset()`**,登出/重置一律手动清字段(登录时 getAuthInfo 无条件覆盖)。

## 9. 组件规范

- 页面组件 ≤300 行(生成器骨架 + 槽位补齐通常达标);超限按"搜索区/表格/弹窗"拆子组件。
- props 用 TS 类型(`defineProps<T>()`);跨页面组件进 `src/components/` 并配最小 demo 注释;页面私有组件放同级 `components/`。
- 样式:`scoped scss` 写业务样式,UnoCSS 只做布局原子类;**禁全局污染选择器**(需要 :deep 时限定本组件根类名)。
- 图标统一 `@element-plus/icons-vue` 按需 import(全量注册已移除);菜单 icon 用底座 SelectIcon 体系。

## 10. 安全红线【前后端同规,违者返工】

- token 仅存 localStorage(persist),**禁写 cookie**;凭证类字段(appSecret/accessToken)**沿用后端脱敏直显,禁前端二次还原/掩码运算**。
- **禁 console.log/response 打响应体、禁 alert 调试残留提交**;oxlint no-console 拦 error 以外输出。
- 明文密码提交走 HTTPS + 后端 BCrypt,**前端禁做摘要/加盐**(改变字节序导致后端校验失败)。
- mock 数据禁入生产构建(`.env.production` 不留 mock 地址);`tools/openapi.json` 是契约快照非密钥,**禁把任何真实凭证/密钥写进 erp-web 任何文件**(密钥一律环境变量,同 docs/07 §7)。

## 11. 工程纪律【生成器优先 = Token 纪律前端版】

- **门禁四件:`pnpm type:check` + `pnpm lint` + `pnpm lint:stylelint` + `pnpm build` 全绿才算完成**;erp-web 无独立 .git(husky 不生效),门禁以手动执行为准,提交前必跑。
- **新 CRUD 页一律:`api:sync` → 写 `tools/specs/<domain>.txt` → `gen:page` → 人工补 TODO 槽位**,禁从零手写同构样板;同构页面第二次出现时主动提议沉淀进生成器模板(人工拍板)。
- spec 是拍板表:**改页面结构先改 spec 再重新生成**(`--force` 前 diff 人工改动);生成文件头注明重生成规则。
- 生成器产出的 `TODO(#编号)` 与后端同规:编号必须登记 TODO.md,禁裸 TODO;tools/** 已排除 oxlint(CLI console 正当)。
- 提交纪律:纯前端改动与后端改动**分开提交**;openapi.json 快照随契约变更提交,commit 里可见接口增减。

## 12. 反模式对照表(发现即还债)

| 反模式 | 正解 |
|---|---|
| 组件内 import axios / 拼 URL | 请求收敛 `src/api/apis/`,路径 `/api` 全路径(§2) |
| 页面再解一层 `res.data` | 拦截器已解包,业务只见 data(§3.1) |
| 页面里换算 records/list / pageNo/pageNum | 差异只在生成的 page 函数收口(§3.3) |
| 金额过 parseFloat/Number 运算 | string 直存直显;计算需拍板引 decimal 库(§6) |
| 造 refresh token / 续期轮询 | 401 即重登(§3.5) |
| 裸 TODO / 槽位无编号 | TODO(#编号) 登记进 TODO.md(§11) |
| 绕过生成器手写 CRUD 样板 | api:sync → spec → gen:page → 补槽(§11) |
| component 无视图静默白屏 | console.error 显式报错(§7) |
| console 打响应体 / 调试残留 | 禁;oxlint 拦截(§10) |
| 手抄后端字段自造类型 | api:sync 快照为准,类型 import 收口(§2) |
| toolbarLeft prop 传 auth 期待鉴权 | 无效 attr;按钮 v-auth 收口在页面(§4) |
| 操作列不写 #operation 插槽 | v2 必须提供,否则运行时报错(§4) |
| pnpm up 追大版本 | 锁 lockfile;升级拍板(§1) |
| `$reset()` 清 setup store | 手动清字段(§8) |
